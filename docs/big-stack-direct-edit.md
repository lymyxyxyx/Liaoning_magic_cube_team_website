# 大堆榜展示与直接编辑（2026-10-10）

`/weekly/big-stack` 对游客和管理员显示：排名、周赛编号、姓名、WCA ID、性别、一小时还原数量。移除来源列。编号/WCA 缺失时单元格留空，性别不确定时显示“未知”。管理员每行仅保留“编辑”；登录权限保持不变。

编号从原周赛选手库读取，不分配独立大堆号码。匹配优先采用明确的选手 ID、精确 WCA ID；无明确身份时仅采用唯一的完整姓名匹配。WCA 从可见辽宁魔友库获取，采用精确 ID 或唯一完整姓名。WCA 双语姓名中的括号内完整中文姓名可以精确匹配中文录入名，不使用拼音、部分姓名或模糊搜索。同名、身份 ID 冲突和性别证据冲突不猜测。不为展示匹配改写历史成绩或自动持久化绑定。

页面内提供管理员登录，登录后留在当前大堆项目。手机端采用较紧凑的表格列宽，保留表格内横向滚动。

日常流程：每行编辑 → 改姓名/数量、选择已有周赛编号、维护 WCA ID/性别 → 保存。周赛编号字段用于关联已有编号，无编号可留空。日期、备注、修改说明和删除置于“更多信息”；新增、Excel 导入、历史统一折叠在榜单上方。日常保存可不填写说明，服务自动记录“大堆榜直接编辑”。删除仍需原因和确认。

关联选手的 WCA 修改与大堆记录保存使用同一事务，同步该选手其他已绑定大堆记录，并保留共享身份审计和成绩修订。成绩或编号校验失败、身份冲突、旧版本保存时全部回滚，避免前一步已保存而后一步失败。编号对应原选手档案，不能凭空起号。性别可使用自动匹配，也可以管理员明确指定男、女、未知；人工指定保存在大堆记录 gender_override，不覆盖魔友库。

公开接口仅返回展示字段，不返回内部选手 ID、候选匹配 ID、编辑版本或备注。展示字段会在页面、列表接口、新增/修改返回及导入返回中一致补齐。
